# Track: Multi-Language SDK Development (PHP & Python)

**Problem**: TokenTalos is currently easiest to use in Node.js environments. Other platforms (like Macrodash's Python backend or PHP applications) need a standardized way to interact with the TokenTalos Gateway without writing raw HTTP calls.

**Solution**: Develop official, lightweight SDKs for PHP and Python that provide a consistent interface for prompt execution, construction, and tracking.

- **Phase 1: Python SDK Implementation**: ⏳ IN PROGRESS
- **Phase 2: PHP SDK Implementation**: 📅 PLANNED
