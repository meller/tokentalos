# Track TD-015: Fix catastrophic-backtracking DoS in prompt construction (PII regex + BPE tokenizer)

**Lane**: done
**Lane Status**: success
**Progress**: 100%
**Update**: Implemented and verified live, not just benchmarked in isolation. Two independent O(n²)-class bugs found on the same request path: (1) `pii_detector.js`'s `email` regex — unbounded quantifier before a possibly-absent `@`, 18.2s on a 100K-char non-matching input, fixed by bounding both quantifiers (RFC 5321 lengths). (2) `lib/engine/tokenizers.js`'s `countTokens()` — `js-tiktoken`'s BPE encode() on every prompt part, every `/execute` call, no feature flag gating it, 25.9s at just 20K chars on a repeated-character run — fixed with a cheap O(n) repeated-run guard that routes pathological input to the existing length-estimate fallback, leaving normal prompts on the exact-BPE path. Fixing (1) alone did **not** fix the live hang — proved (2) was independent, not a symptom of the same bug. A third, lower-severity `express.json()` body-limit fix (10mb, was undeclared ~100kb) was folded in from the same investigation. All three verified together: the original 6x 90-150KB worst-case reproduction that pegged the process at ~46% CPU and made it fully unresponsive for minutes now completes every request in 0.37-1.11s, with CPU back to idle. `npm test`: 9 suites / 28 tests, all passing.
**Phase**: Implemented, verified live, tests passing. Ready for quality-gate review.
**Type**: bugfix
**Summary**: Found while investigating severe chat latency in a downstream project (MakroDash). A local `tokentalos start collector` instance pegged at ~46% CPU and became fully unresponsive (accept queue backed up, every route including `/api/v1/health` unreachable) for minutes after a handful of ~90-150KB requests. Root cause was two independent catastrophic-backtracking bugs (PII email regex + BPE tokenizer), not payload size — a downstream prompt's *shape* (a long unbroken run of matching characters), not its size, is what triggers either one. Both fixed; neither affects detection accuracy or token-count accuracy for normal prompts.
